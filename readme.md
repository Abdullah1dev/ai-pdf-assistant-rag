# AI PDF Assistant (RAG-Based)

A Streamlit-based AI assistant that answers questions from a PDF using Retrieval-Augmented Generation (RAG).

---

##  Features
- Context-based answers from PDF
- Reduced hallucination (strict RAG)
- Semantic search using ChromaDB
- Chat interface with memory
- Streaming responses (ChatGPT-like)

---

## Tech Stack
- Python
- LangChain
- ChromaDB
- HuggingFace Embeddings
- Ollama (Local LLM)
- Streamlit
